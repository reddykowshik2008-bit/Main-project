# Digital UI Collection — BookMyShow, ChatGPT, Amazon, Flipkart

Four separate web-app templates connected from the main uploaded dashboard.

## App 1: BookMyShow
Home → Movie Details → Language & Format → Showtime / Cinema → Seat Count → Seat Selection → Payment → Booking Confirmation

The home page now includes colorful cinema cards with photo thumbnails and additional Chennai / OMR cinemas.

## App 2: ChatGPT
Home → Chat → History / Settings

## App 3: Amazon
Home → Product → Cart → Address → Payment → Order Confirmation

The home page includes 10 demo products and each product opens a dynamic product-details page.

## App 4: Flipkart
Home → Product → Cart → Address → Payment → Order Confirmation

The home page includes 10 demo products and each product opens a dynamic product-details page.

## Design
Colorful gradients, accent cards, responsive layouts and hover states are used across the apps.

## Important
All apps are educational UI demos inspired by common interface patterns. They are not the official websites and do not process real payments.

Cinema names and local information were checked against current Chennai/OMR listings while preparing the demo. Photo thumbnails are web-sourced reference images; replace them with appropriately licensed images before production use.
